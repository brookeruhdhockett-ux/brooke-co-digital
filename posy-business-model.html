The Setup Wizard

Confirmed buildable in 2–3 weeks. No dealbreakers. Feasibility report complete.

What the student experiences (works on phone/iPad):

  1. Open the Posy Setup Wizard in their browser
  2. Create a Hetzner cloud account (~$5/mo)
  3. Paste their Hetzner API token
  4. Paste their Anthropic API key (with $20 spending cap)
  5. Create a Telegram bot and paste the token
  6. Pick which AI employees: Money, Email, Lark
  7. Tap "Deploy"
  8. Server auto-provisions on their account (~60 seconds)
  9. Everything pre-installed, daemon starts
  10. Bot messages them on Telegram within 2 minutes. Done.
No terminal. No coding. No SSH. No desktop required. The entire setup works from a phone. Every competitor requires a desktop and terminal — we're the only mobile-first option.

After setup:

  • ✓ 100% Telegram — talk to bots in the same app they already use
  • ✓ Email Agent monitors Gmail via MCP (secure Google protocol)
  • ✓ Lark Agent connects via official plugin
  • ✓ Server crashes → auto-restarts, we monitor 24/7
  • ✓ "Pause your agents" button stops server and billing instantly
